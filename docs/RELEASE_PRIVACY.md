# 发布前隐私检查

公开源码包采用明确的文件清单，只收录程序源码、界面、必要资源、构建脚本和当前说明。

数据库及其 WAL/SHM 文件、加密 API 凭据、日志、旧版备份、数据目录定位文件、缓存、本地启动脚本 `start.bat`、测试目录、测试截图和报告、虚拟环境、环境变量文件，以及旧 Git 历史均不包含在包中。

## 检查与打包

在项目目录运行：

```powershell
python scripts/release_privacy.py
python scripts/release_privacy.py --source-zip releases/TranslateArena-source.zip
```

脚本检查常见密钥格式、本机用户目录和当前账户名；发现可疑内容、意外资源或符号链接时停止。检查结果只报告文件名和类别，不打印匹配内容。源码包附带重新计算的 SHA-256 校验清单。

Windows 构建也会先执行这项检查。发布可执行程序时，只使用构建输出；发布源码时，使用上述脚本生成的压缩包。不要把本机工作目录、虚拟环境或运行数据目录整体发送出去。

## 首次运行

应用没有内置的个人 API Key。新用户首次运行时自行填写凭据，历史记录从空白开始。数据会保存到该用户自己的本机应用数据目录。

本机清理不会撤销服务商后台的 API Key，也不会删除已上传到服务商或已发布到其他位置的副本。需要停用 Key 时，应在服务商后台撤销。

该检查属于发布前防误带检查，不能代替所有形式的人工隐私审查。
